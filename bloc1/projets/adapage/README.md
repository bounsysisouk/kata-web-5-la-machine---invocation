# Reine Suthida

Ce projet consiste à créer une page web consacrée à la reine Suthida de Thaïlande.

## Outils et technologie utilisés

- HTML5 : structure du contenu.
- CSS3 : mise en forme et présentation visuelle. 

## Organisation du projet

- 'index.html' : page d'accueil présentant la reine Suthida.
- 'cartes.html' : page contenant les différentes sections pesentées sous forme de cartes. 
- 'assets/': dossier contenant les images utilisées dans le projet.
- 'wireframe/' : dossier contenant les maquettes de la structure des pages.
- 'style.css' : fichier qui definit le désign et la présentation des pages.

## Comment consulter le projet ? 

1. Extraire les fichier 
2. Ouvrir le fichier 'index.html dans un navigateur web 

## Bonus : Frise chronologique responsive 

Cette fonctionnalité permet de visualiser rapidement les événements marquants de la vie de la reine Suthida. 
je l'ai développée selon l'approche mobile first, la frise adopte une disposition verticale sur mobile et une disposition horizontale avec défilement à partir de 1024 px. Cette adaptation permet de conserver une mise en page adaptée à la taille de l'écran tout en évitant que la frise provoque un débordement horizontal de la page.
